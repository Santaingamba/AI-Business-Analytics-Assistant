# Frontend UI

This is the React frontend for the AI Business Analytics Assistant.

## Architecture

- **Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: TailwindCSS
- **Routing**: React Router
- **HTTP Client**: Axios

## Setup

```bash
npm install
```

## Running the Application

```bash
npm run dev
```

## Typechecking & Linting

```bash
npm run typecheck
npm run lint
```
